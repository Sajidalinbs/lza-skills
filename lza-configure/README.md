# `/lza-configure`

> 📖 **Full playbook:** [`SKILL.md`](SKILL.md) — this README is a summary for browsing.

Translate the signed-off plan into LZA configuration YAML. **Start from the official AWS
baseline** (LZA Universal Configuration), then customize each file.

- **Invoke:** after `/lza-plan` and `/lza-bootstrap` are complete.
- **Predecessor:** [`/lza-bootstrap`](../lza-bootstrap/) · **Successor:** [`/lza-deploy`](../lza-deploy/)

### What it covers
**Step 0 — seed the config repo from the AWS baseline** (`intake/fetch_baseline.sh`), then a
per-file walkthrough with pitfalls: `replacements-config`, `accounts-config`,
`organization-config`, `global-config`, `security-config`, `network-config`, `iam-config`,
`customizations-config`. The accounts/organization/network YAML can be generated by the
[`intake/`](../intake/) planner. No IPAM, no DNS/central-endpoints VPC.
